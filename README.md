# CodeAlpha E-Commerce Website

A beginner-level full stack e-commerce website developed as part of my CodeAlpha Full Stack Development Internship.

## Features

- Product listings
- Product search
- Product categories
- Product sorting
- Product details page
- Shopping cart
- Quantity controls
- Checkout system
- Order processing
- User registration
- User login
- MySQL database
- Express.js backend

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## How to Run

1. Install Node.js and MySQL.
2. Create the `shopease` database in MySQL.
3. Run `npm install` in the project folder.
4. Create a `.env` file and add your MySQL password.
5. Start the backend using `node BACKEND/server.js`.
6. Open `FRONTEND/index.html` in a browser.
